# Foodgram

Foodgram — сервис для публикации рецептов. Пользователи могут создавать рецепты, добавлять их в избранное, подписываться на авторов и выгружать список покупок.

Адрес сервера: `https://foodgraam.servebeer.com`

## Технологии

- Python 3
- Django
- Django REST Framework
- Djoser
- PostgreSQL
- Gunicorn
- Nginx
- Docker
